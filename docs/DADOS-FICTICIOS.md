# Dados fictícios

Os dados do desafio são fictícios e não têm ligação com nenhuma empresa real.
Neste repositório, nomes de marcas, transportadoras, o endereço do proxy de IA
e os identificadores de conversas (`CV000001`...) e de pedidos (`PED000001`...)
são inventados. Os CSVs do desafio não fazem parte do repositório (a pasta
`data/` fica fora do git). Para rodar o pipeline e os testes que leem os CSVs,
é preciso fornecer um conjunto de dados com o mesmo formato e com esses
identificadores.
